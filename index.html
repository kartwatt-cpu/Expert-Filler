Browser extension

ResumeFiller

Fill recruitment application forms with resume information you choose to save locally. ResumeFiller suggests matching data, previews full-page fills, and never submits applications.

Public review materials

ResumeFiller stores resume data, attachments, preferences, and field-matching choices locally in the browser. The developer does not receive this information.

Privacy policy Public test form GitHub repository
  • No account or test credentials are required.
  • The extension does not execute remote code or transmit resume data to the developer.
  • Forms are never submitted automatically.
